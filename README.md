# 智能教室系统
## 主要功能
在桌面上置底设置课程表，当日值日生表

启动时最小化到托盘，点击图标打开设置

设置内能够：
输入课程表（每节课有属性：科目，时间，星期几）
输入学生列表（学号，姓名）
设置值日组别（id,成员，各成员职务（擦黑板，扫地，倒垃圾））
设置每日值日生（在日历上指定）
设置开机自启动

提醒功能：
每个学生有一个social credits属性，初始值为50
在每节课后提醒老师下课，值日生擦黑板
在放学时提醒值日生做值日
在每节课上课是询问老师黑板是否擦，若是，擦黑板social credits+1,若不是,-1，若10分钟未作答，关闭对话框
在开机是询问昨日各项值日是否完成，完成+5，未完成-5
提供导出报表功能
